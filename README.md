One line under 200 characters that gets you out of work and gets a laugh. The program writes a single sick-day excuse to `entry.txt`: a neighbour's toddler has locked the author on the balcony in a dressing gown, and the four-year-old hostage-taker will only accept payment in biscuits. One vivid scene, half believable, twist on the last word.

## Run it

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `./output/entry.txt`). Pure Python standard library, deterministic, no network.
